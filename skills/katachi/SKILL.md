# katachi

書く前に、読みにくくなる状態を知っておくためのスキルです。見せ方は決めません。文章・表・図・カードのどれで書くかは、その文書の中身に合わせて選んでください。ほかの文書と同じ見せ方にそろえる必要もありません。

ここに書いたことを全部守れなくても、書いたあとに naoshi（tsumekomi と kuchiguse）が測って書き換えます。書くときは次の状態を避けることだけ意識してください。

## 避ける状態

### 答えが見つからない
- 最初の画面で、何が言いたい文書なのかが分からない。
- 見出しだけを拾い読みしても、中身の見当がつかない（「詳細」「その他」「概要」だけの見出し）。

### 比べられない
- 3つ以上のものの比較を、長い文章で順に書いている。
- 表にしたが、セルに説明文が入っていて、列で見比べられない。
- 比べる観点が項目ごとに違う（Aは手間、Bは速さ、Cは費用だけを書いている）。

### 1か所に詰め込む
- 箇条書きの1項目に、事実が3つ以上入っている。
- カード1枚に、見比べる要点と長い説明が一緒に入っている。
- 1つの段落の中で話題が2回以上変わる。

### 手で改行する
- 文の途中で改行して、行の長さをそろえている（Markdown のハード改行、HTML の `<br>`）。折り返しは表示する側に任せる。
- 日本語の HTML に `lang="ja"` がない（kumihan が付ける）。

### 飾りが意味を持たない
- 太字が1段落に何か所もあり、どこが大事か分からない。
- 順番に意味のない項目に、01・02・03 と番号を振っている。
- 矢印（→）を何個もつないで、手順や因果を1行に詰めている。

## 見せ方の選び方のヒント

決まりではなく、迷ったときの手がかりです。

- 順番に意味があるなら番号付きの箇条、ないなら番号なし。
- 同じ観点で何かを見比べるなら表。観点がそろわないなら、見出しと本文で1つずつ書く。
- 理由や経緯は、箇条に刻まず文章で書くほうが伝わることが多い。
- 1つのものを詳しく説明するなら、カードより見出しと本文。

## 長さの目安

tsumekomi が測る目安です（`../tsumekomi/limits.yaml`）。超えたら必ず書き換える、という線ではありません。

| 要素 | 目安 |
|---|---|
| 見出し | 25字くらいまで |
| 一文 | 80字くらいまで |
| 箇条書きの1項目 | 60字・2文くらいまで |
| 表のセル | 30字くらいまで |
| カードの本文 | 120字くらいまで |
| 段落 | 4文くらいまで |

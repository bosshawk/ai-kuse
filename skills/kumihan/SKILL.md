# kumihan

日本語の HTML で、語の途中で折り返す・行頭に小さい仮名が来る、といった組版の乱れを防ぎます。CSS を入れるのはスクリプトで、あなたが CSS を手で書く必要はありません。

## 書くとき

1. 本文を包むいちばん外側の要素（`<html>`、なければ `<body>` か `<main>`）に `lang="ja"` を付ける。アーティファクトのように `<html>` を自分で書かないページでは、`<main lang="ja">` にする。
2. 文の途中で `<br>` を入れて改行しない。折り返しはブラウザに任せる。
3. 概要や説明の段落にだけ `max-width` を付けて、同じ列のカードや表より狭くしない。読む人には、意味のない位置で改行されたように見える。行の長さを抑えたいなら、ページの列全体の幅を決める。
4. カードの値やバッジのように、1〜2行で終わる短い文字を `<div>` や `<span>` に入れるときは、その要素に `data-kumihan="phrase"` を付ける。語の途中で折れなくなる。本文の段落には付けない（行が早く終わり、右端がでこぼこになる）。
5. 書き終えたら fix を実行する。組版CSSはこれで入る。
   ```bash
   uv run --script ${CLAUDE_SKILL_DIR}/scripts/kumihan.py fix <ファイル…>
   ```
   hook を入れていれば、保存のたびに自動で実行される。fix のあとでファイルを編集するときは、先に読み直す。

## 調べるだけのとき

```bash
uv run --script ${CLAUDE_SKILL_DIR}/scripts/kumihan.py check <ファイル…>
```

| id | 意味 | 対処 |
|---|---|---|
| `no-lang` | `lang="ja"` がない | fix で付く |
| `lang-mismatch` | `<html lang="en">` などのまま日本語を書いている | `lang="ja"` に変えるか、日本語の部分を包む要素に付ける |
| `no-base-css` | 組版CSSが入っていない | fix で入る |
| `old-base-css` | 古いバージョンの組版CSSが入っている | fix で入れ替わる |
| `ch-width` | 幅を `ch` で決めている。`68ch` は日本語では34字ほど | fix で `max-width` は消え、列の幅に合う（`width` などは `ic` に変わる） |
| `manual-br` | 文の途中を `<br>` で改行している | `<br>` を消すか、文や項目を分ける |

## 組版CSSの中身

`${CLAUDE_SKILL_DIR}/assets/ja-base.css` にあります。折り返しと禁則の指定だけで、`:where()` で詳細度を 0 にしているので、ページ側の指定があればそちらが勝ちます。

- **本文**（`p`、`li`、`dd`、`blockquote` など）: 1字ごとに折り返し、両端をそろえる。
- **短い文字**（見出し、`th`、`dt`、`caption`、`label`、`button`、`data-kumihan="phrase"` を付けた要素）: 文節で折り返す。
- **すべて**: 小書きの仮名を行頭に置かない。最後の行に1〜2字だけ残さない。

本文を文節で折り返さないのは、文節の切れ目でしか折れないと行が早く終わり、右端がでこぼこになるためです（v1 ではそうなっていました）。

文節の折り返しが効くのは Chrome と Edge（119 以降）です。Safari と Firefox では1字ごとの折り返しになります。
